Rules we never break

  • Every match says what's similar, how similar, and where it breaks down.
  • Every number comes from a named dataset. Missing data shows as missing; we never guess.
  • NASA data does the main work.
  • We test our method on known analog sites first (Atacama, Haughton Crater, the Dry Valleys).
  • AI use is labelled where judges can see it.

How we're judged

Five criteria, each scored 1 to 5:

ImpactCreativityValidityRelevancePresentation

Most of the score comes from our project page. The 30-second demo mainly lifts Presentation.
