# Rules on work before the event

- NASA's official [Participant FAQ](https://www.spaceappschallenge.org/resources/participant-faqs/) says teams may not begin working on the challenges before the hackathon. This was read through search results only, because spaceappschallenge.org doesn't load on this PC. Confirm it on the page.
- A third-party summary of the 2026 judging rules ([colabcomps](https://colabcomps.com/competitions/c/nasa-space-apps-challenge-de63f4b0/rubric)) says research and looking at data early are fine, all project code and assets must be created during the 48-hour event, and pre-existing tools must be disclosed.
- Event: 14–15 November 2026.
