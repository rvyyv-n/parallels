Scope: the single-page analog finder (site/index.html). Mode: Operate.
Audience and job: judges and newcomers pick a target, a challenge, and an Earth site, and read why it matches and where it breaks, in under a minute.

## Direction contract
seed: none (pinned) — the user pinned the world (plain editorial: one accent colour, hairline rules, table-like layout, DIN-style headings; no gradients, pastel pills or fake planets) and the brief pinned the flow.
THESIS: a survey ledger, not a dashboard. Refuses the dark space-themed card grid with glowing planets.
OWN-WORLD: cool paper-white ground, near-black ink, one cobalt accent; hairline 1px rules; Barlow (DIN-like) headings, system UI body, tabular numerals; sample values drawn with diagonal hatching and the word "sample".
STORY: the visitor learns that no Earth place copies a Moon base whole, so each challenge gets its own best Earth sites, each with an honest gap.
FIRST VIEWPORT: target picker and challenge list beside the map, a ranked site table, the top match's card already open.
SIGNATURE: the gap ruler — each trait drawn as a line from the Earth value to the target value in real units, with the Earth rank beside it.
RISK: dense tables can intimidate newcomers; plain-language row labels and one sentence per challenge carry them.
